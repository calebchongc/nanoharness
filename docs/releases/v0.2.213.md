# NanoHarness v0.2.213

## Highlights

- **Eliminate mouse-down UI freeze on long math-heavy transcripts (#38, #39):**
  - Keeps offscreen row culling enabled during mouse-down and active drag selection, pinning only the active selection's row span so clicking or dragging stays viewport-proportional while preserving cross-paragraph selection, scroll-while-dragging, and exact offscreen Copy.
  - Removes the redundant pre-layout `c.changed = true` rebuild loop in `native_math_flow`, letting `layout_dependent` perform a single bounded post-layout reconciliation instead of four full-tree build passes.
  - Defers SVG rasterization in `ui.svg` from `build()` to paint time (`Images.registerSvg`), letting paint-time clipping skip offscreen equation SVGs and keeping visible SVGs under `Images.get`'s per-frame decode budget.
