# NanoHarness v0.2.210

## Highlights

- **GPT-6.2 Sol / Astra, Model Refresh & Ultra Fast speed tier (#27):** Added `gpt-6.2-sol`, `gpt-6.2-astra`, and `gpt-6.1-sol`, a `Speed` segmented control (`Standard · Fast · Ultra Fast`) in the compact model picker persisted across open and new chats, an explicit Refresh button in the model picker search bar (`force: true` live probe without slowing startup), and `nanoattention:flint` model ID normalization.
- **Native Flint setup & downloads (#16):** Added the Native Flint card in **Settings → Agents** linking directly to the licensed INT4 weights and SHA-256 manifest at `codegraff.com/flint`.
- **Direct `Cmd+T` / `Cmd+N` new tabs & macOS color emoji (#21):** `Cmd+T` and `Cmd+N` open a new tab directly instead of the folder chooser; macOS and iOS color emoji now preserve full BGRA8 RGB detail alongside native text rendering.
- **Refreshed native GitHub UI (#25):** Polished repository browser, pull request list and detail headers, semantic state badges (`Open`, `Merged`, `Draft`), branch flow pills, file diff cards, and activity timeline.
- **Desktop selection, scrolling, and math fixes (#13, #20, #21, #24, #28):**
  - Preserved inactive split-pane historical scroll positions when selecting text, and kept transcript scrolling viewport-proportional while retaining offscreen cross-paragraph Copy (#22 / #28).
  - Isolated sibling display-equation selection IDs so selecting one formula never highlights or copies unrelated equations (#28).
  - Fixed stuck selection gestures after focus loss or missed mouse-up (#24).
  - Kept queued prompt actions (`Edit`, `Steer`, `Remove`, `Send now`, `Save to queue`, `Cancel`) and `Scroll to bottom` visible and wrapped in narrow panes (#13, #20).
  - Added **Copy image** to image previews, anchored the project picker to the active tab, fixed inline-math list width and rejected LaTeX table overflow, and used file-generic wording for attachment-only messages (#9, #21).
- **Local M3 release & TestFlight routing (#26):** Routed TestFlight release uploads through local Apple Silicon workers with automatic GitHub cloud fallback when offline.
