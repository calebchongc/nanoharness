# NanoHarness v0.2.206

## Desktop Markdown & Sidebar

- **Escaped bars in Markdown table cells (`justrach/harness#889`):** Preserves escaped vertical bars (`\|`) inside Markdown table cells, LaTeX math spans (`$\|x\|$`), and inline code spans instead of splitting columns.
- **Auto-hide `Cmd+B` sidebar scrollbars (`justrach/harness#845`):** Hides overflowing sidebar scroll rails after three idle seconds across Developer and Zen modes, ignoring stationary hover while keeping active thumb drags visible.

## Agent Engine & MCP Parity

- **Capability error classification (`justrach/codegraff#1907`):** Avoids misclassifying provider `unsupported_capability` errors as `Signed out` across shared desktop and mobile run-error parity rules.
- **MCP `readOnlyHint` tool annotations (`justrach/codegraff#1908`):** Marks the 11 read-only Harness MCP inspection tools (`whoami`, `list_devices`, `list_projects`, `list_harnesses`, `list_models`, `list_chats`, `get_chat`, `read_chat`, `list_rooms`, `room_inbox`, `list_bots`) with `readOnlyHint: true`.

## NanoHarness Auto-Updater

- **NanoHarness release feed & Windows relaunch handoff:** Points update manifest checks to `justrach/nanoharness` (`manifest.json`) and supports `--wait-for-exit` in `harness-cli` to coordinate Windows self-update relaunch and `.old` cleanup including `harness-engine.exe.old`.
