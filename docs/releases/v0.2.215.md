# NanoHarness v0.2.215

## Authentication & In-App Browser

- **OpenAI passkey login on iOS & desktop system-browser handoff (#69):** Replaces `WKWebView` in iOS `ChatGPTSignInBrowser` with `SFSafariViewController` paired with a strictly loopback (`127.0.0.1`) callback catcher so Face ID / iCloud Keychain passkeys and Google sign-in work natively in-app and auto-return on redirect. On macOS desktop, wires `WKUIDelegate` popup handling and live URL sync across redirects in the integrated browser, and shows an inline handoff banner with one-click `Open in browser` on OpenAI passkey auth routes.

## Desktop UI & Navigation

- **New project folder layout fix & folder picker UX polish (#68):** Fixes the vertical height blowup after selecting a working folder in `New project` (caused by wrapping device text inside a zero-width flex column), frames both empty and selected working-folder rows cleanly, and aligns the `Add folder` navigator breadcrumbs, path bar, search box, and folder list.
- **Aligned sidebar disclosure arrows (#55, #56):** Keeps disclosure arrows in the same trailing column across Pinned, project, and Archived sidebar headers while placing the hover-only `+` new-session action before the arrow.
- **Windows tab-strip test geometry (#70):** Accounts for Windows's trailing caption buttons (`window_chrome.trailing`) in the `#47` tab-strip tests so cross-platform Windows releases pass cleanly.
