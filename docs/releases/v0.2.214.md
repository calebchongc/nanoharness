# NanoHarness v0.2.214

## Desktop UI & Navigation

- **Project picker dismissal & shortcut toggle (#42, #61):** Dismisses the project picker on outside pointer press and toggles cleanly with `Cmd+Shift+P`.
- **Wrapped composer notice banner (#44, #62):** Moves composer notices out of the compact input row into a dedicated, keyed, width-bounded wrapping banner above the composer pill with a dismiss control, preserving draft text, focus, caret, selection, and undo history.
- **Workspace navigation & projectless tab placement (#47, #66):** Prevents `Cmd-3` and tab navigation from silently grouping projectless conversations (`spaceId == null`), and keeps all open global workspaces visible alongside active single-pane local panel tabs across both the top strip and the overflow menu.
- **Vertically centered compact sidebar rows (#59, #60):** Centers single-line compact sidebar session row content vertically inside its box across Developer and Zen modes.
- **Selection gestures, continuous edge scroll & macOS text access (#48, #49, #50):** Shares source-byte `2 = word / 3 = sentence / 4+ = paragraph` selection across output prose, the composer, and expanded Write without collapsing held multi-clicks; adds bounded edge scrolling while dragging; and exports selected source text and UTF-16 ranges via macOS accessibility.

## Desktop Backlog, Actions & Agent Work

- **Project Actions reconnect recovery (#45, #64):** Defers initial `ListProjectActions` loads while disconnected so transient startup/restart gaps do not poison the project cache with `"not connected"`, filters stale replies by request ID, and retries failed/loading snapshots automatically on engine reconnect without retrying real server errors every frame.
- **Model picker activation, copy ticks, file-drop shading & Tool Access (#51, #52, #53, #58):** Handles plain `Return` in the model search field and clicks on `↵ Configure`, restores the 1.2-second checkmark across remaining desktop copy controls (browser address, code/Mermaid blocks, notices, GitHub snippets, sandbox IDs), restores the per-pane drop-target scrim and `Drop to attach` label, and removes the redundant `Failed` pill from Tool Access cards.
- **Live subagent & task progress surfaces (#58):** Ports normalized structured todos, live subagent tails, parked waiting state, and the Agent Work footer/popover fed from `requests.watchToolProgress`.

## Math Rendering & Engine Security

- **Explicit LaTeX spacing around relations (#46, #54):** Preserves both explicit TeX spacing commands and automatic spacing around relation operators (`=`, `\longrightarrow`, etc.) instead of falling back to literal source.
- **Dependency security updates (#57):** Updates `p256`, `crypto-bigint`, `zip`, `rusqlite`/`libsqlite3-sys`, `quinn-proto`, `quinn-udp`, `rustls`, `rustls-webpki`, `webpki-roots`, `rustix`, `tokio`, `heapless`, and `chacha20`, resolving 24 `cargo-audit` advisories in the engine workspace.
