# NanoHarness v0.2.216

## Desktop File Drop & Clipboard

- **macOS Finder file-reference drag-and-drop (#43, #72):** Resolves local macOS `NSURL` drops (including Finder `file:///.file/id=...` file-reference URLs) through Foundation `filePathURL` / `path` at the AppKit boundary before discarding the `NSURL`, while preserving remote/non-file rejection and guarding `clipboard.readFiles` identically.
- **Actionable drop failure notices (#43, #72):** Rejects unresolved `/.file/id=...` paths explicitly instead of attempting POSIX reads against them, and distinguishes non-local URLs, unresolved file references, folders, missing/unreadable files, empty files, oversize (>24 MB) files, and staging errors without exposing paths or reference IDs.

## Documentation

- **Direct curl download instructions:** Documents downloading NanoHarness release binaries with `curl`.
