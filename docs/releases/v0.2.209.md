# NanoHarness v0.2.209

## Release Automation & Signing

- **Automated GitHub Actions macOS release pipeline:** Builds, signs (`Developer ID Application`), notarizes, staples, verifies `LC_BUILD_VERSION minos <= 12.0` (`<= 15.0` for bundled `graff`/`codedb`), and publishes all platforms (`macOS`, `Linux`, `Arch`, `Windows`) directly from GitHub Actions via `cut-release.yml` and `release.yml`.
